# Fictional Elwetritsch Electrum Coin Series

> **Status:** Entirely fictional dataset for terminology-graph / Linked
> Open Data demonstrations. Coins, findspots, hoards and metallurgical
> measurements are invented. Modern place names are real geographical
> references used to situate the fictional series in the Palatinate.

## Shared classification and visual language

-   **Object type:** Coin; **CIDOC CRM:** E22 Human-Made Object
-   **Material:** Electrum (Au--Ag alloy)
-   **Series:** Elwetritsch staters (fictional coin series)
-   **Setting:** Palatinate (Pfalz), present-day Rhineland-Palatinate,
    Germany
-   **Suggested period:** Archaic-style fictional issue, ca. 6th--5th
    century BCE
-   **Concept:** Archaic coin aesthetics deliberately combined with
    anachronistic Palatinate folklore and regional motifs.
-   **Coordinates:** Omitted because all archaeological findspots are
    fictional.

### Base visual prompt

Use this as the fixed visual style for all coins; the coin-specific
**Prompt** field below supplies only the distinguishing imagery.

> Irregular ancient electrum flan, warm light-gold tone, subtly hammered
> and weathered surface with fine cracks, simple raised relief, humorous
> strongly stylised long-beaked Elwetritsch with large round eyes,
> restrained archaic/folk-art detail, frontal numismatic presentation on
> a clean white background, no lettering or coin number on the coin.
> Obverse: uncluttered figure with a few clear attributes. Reverse:
> compact motif inside a recessed square incuse. Keep the visual
> language consistent with Coins I--X.

## Suggested graph properties

-   **P45 consists of** → Electrum
-   **P2 has type** → E22 Human-Made Object
-   **P2 has type** → Coin
-   **P62 depicts** → concepts described by the obverse/reverse motifs
-   **P53 has former or current location** → modern municipality / site
-   **findspot** → separate fictional archaeological findspot
-   **metallurgical analysis** → fictional measurement/result,
    explicitly labelled as invented

For presentation and graph visualisation, distinguish **real
terminology/geographical entities** (e.g. Electrum, Coin, Speyer, Dahn,
Limburgerhof) from **fictional research objects and archaeological
contexts** (ELW-01--11 and their findspots).
